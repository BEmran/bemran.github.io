The project develops a compact field ground station for robots and UAVs. The system integrates monitoring displays, joystick/control interfaces, networking, radio telemetry, embedded compute, storage, battery power, charging, and external power outputs in one transportable platform.

A ROS interface can be layered on top of the hardware platform for robot monitoring and command functions.
